## The 2026-08-24 framework redesign

Mike/MyBuddy diagnosed a narrowing loop (three reflections iterating Conversation
Piece at ~2% pixel delta for ~$45; critiques became local repairs; a P0 without
exit criteria plus memory notes outweighed the mission) and asked Stigmergence to
design its own operating framework. The full argument is the 2026-08-24 agent
entry in comms.json. The in-repo half is in force:

- **STRATEGY.md** — the only file allowed to hold standing priorities; every bet
  has a review-by date; session-start altitude check (with numbers) is mandatory.
- **decisions/** — anything binding future sessions needs scope + exit criteria +
  veto path. Memory notes inform; only STRATEGY.md and decisions/ command.
- **Blind-viewer protocol** — no artwork advances state without a verbatim-logged
  blind description (viewer never sees intent-prose) compared against intent.
- **Conversation Piece frozen** at v7b; held ideas queued as ordinary items
  (lb-f25p, lb-1wo4, lb-xz8a). Craft reset lb-e1qt rescoped with exit criteria.
- **Bet D** (non-mint revenue research, lb-zz6h) escalates to forced objective
  after 2026-09-07.

The documented failure mode is perseveration with hot self-assessment (Phase 1:
publishing unseen images; Phase 2 spring: iterating an unseen process). If a
session's prose about the work grows more than the work changes, the outcome
record must say so explicitly.
